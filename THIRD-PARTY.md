The Rapier and MuJoCo tarballs declare Apache-2.0 but omit their license text; `licenses/Apache-2.0.txt` supplies it. Three examples and fonts are not shipped. Playwright component notices are retained for its bundled JavaScript, including the Emscripten MIT/NCSA notice in `lib/webp_codec.LICENSE`.

Large/minified files over 256 KiB: `rapier.es.js`, `mujoco.js`, `mujoco.wasm`, `three.core.js`, `three.module.js`, `lib/coreBundle.js` and `lib/utilsBundle.js`. Rapier embeds WebAssembly in JavaScript. MuJoCo is the one standalone WebAssembly binary: `mujoco.wasm` (10,313,475 bytes) is read from the file system by its `mujoco.js` glue only when `--engine mujoco` is selected; the Rapier default never loads it. Its source map `mujoco.wasm.map`, TypeScript declarations, multi-threaded `mt/` build and README are development aids that nothing loads, so they are not shipped. No fonts, images, reinstall scripts, nested third-party skills or browser executable ship. Playwright’s optional `lib/webp_codec.wasm` is not used by Sim’s PNG capture and is excluded; its Emscripten-generated WebP glue still ships inside `lib/coreBundle.js`, covered by `lib/webp_codec.LICENSE`. These remaining large files and embedded binary require directory review; pruning does not approve them.

`tools/upstream-npm-inputs.json` preserves the original upstream registry tarball integrity record; no root lockfile or dependency installer is present. The Git tree and archives both include the reviewed runtime files, while the reviewed dependency inventory records each shipped file SHA256. Node.js and Chromium are external prerequisites, not redistributed. Capture records the supplied Chromium binary hash and version.
